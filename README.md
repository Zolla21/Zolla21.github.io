# Zelalem Fissiha Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript. It is designed for GitHub Pages and uses a teal and navy visual identity.

## Project structure

```text
Zolla21.github.io/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/
│   └── zelalem.jpg
├── documents/
│   └── Zelalem_Fissiha_CV.pdf
└── README.md
```

## Before publishing

1. Add your portrait photo as `images/zelalem.jpg`.
2. Add your current CV as `documents/Zelalem_Fissiha_CV.pdf`.
3. Replace `zelalem.fissiha@example.com` in `index.html` with your professional email address.
4. Review the project descriptions and replace portfolio themes with verified project details, repository links, and outcomes.
5. Update the LinkedIn URL to your actual profile.

## Run locally

Open `index.html` in a browser. No build process or package installation is required.

For a local server, open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Upload the files and folders to the root of your GitHub Pages repository.
2. Open repository **Settings**, then **Pages**.
3. Select **Deploy from a branch**, choose `main`, and choose `/ (root)`.
4. Save and wait for the deployment to finish.

The site uses relative file paths, so it can work from the repository root on GitHub Pages.

## Accessibility and responsive features

The site includes responsive navigation, keyboard support for the mobile menu, visible focus access through a skip link, reduced motion support, and scroll reveal effects.
